## Animation requirements

Use Motion for React using patterns like:
- `whileInView` for scroll-triggered reveal;
- `useScroll` and `useTransform` for subtle scroll-linked effects;
- `useSpring` to smooth scroll progress;
- staggered reveals for project cards;
- subtle parallax in the hero;
- scroll progress indicator;
- hover microinteractions on project cards;
- animated data/map lines;
- section transitions.

Important:
- animations must be premium and subtle;
- no excessive bouncing;
- no childish effects;
- no motion that hurts readability;
- avoid animating layout-triggering properties;
- prefer transforms and opacity;
- respect `prefers-reduced-motion`;
- use `viewport={{ once: true }}` for reveal animations unless a repeated effect is intentional;
- animations must remain smooth on mid-range phones.

Use the following reference patterns:

- `whileInView` for fade-up reveal.
- staggered children for grouped project cards.
- `useScroll` for top progress indicator.
- `useTransform` for subtle parallax.
- `useSpring` for smoothing scroll values.
- transforms: x, y, scale, opacity.
- avoid expensive computations in scroll callbacks.
